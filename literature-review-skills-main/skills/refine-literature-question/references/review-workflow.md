# Evidence-Grounded Review Writing

Apply alongside `source-integrity.md` and `output-contract.md`. This workflow supports drafting from evidence; it does not claim to perform a complete systematic review automatically.

## Choose The Review Type

Record whether the task is a thesis/narrative review, scoping review, systematic review, conceptual/historical review, or bibliometric mapping plus content synthesis. Explain the choice briefly. Do not force a causal question onto a mapping or interpretive task. Do not label a narrative search systematic merely because it uses a table.

## Search And Selection

Create a search plan with concepts and bilingual synonyms, candidate databases, inclusion/exclusion criteria, language/time/geographic boundaries and citation chaining. Log each actual search: database, exact query/fields/filters, date, exported count and access limits. Unexecuted queries are explicitly proposals. Do not fabricate counts, database access or retrieval results.

For Chinese literature, preserve Chinese titles and record database exports as provided. If CSSCI/core-journal filters are chosen, record the list edition and justify exclusions. Check theses, books and grey literature according to review purpose. Keep translated titles as translations, not verified alternate titles. Format references in the user-specified style only from available metadata.

For systematic/scoping reviews, agree on a protocol, keep screening decisions and exclusion reasons, distinguish records/reports/studies, link overlapping reports, and disclose reviewer arrangements. Do not invent PRISMA counts or describe a single unchecked pass as independent screening. Database access may require user-supplied exports.

## Evidence Table

Use stable source IDs and preserve original records. Extract only what was read:

| ID | Original citation and status | Read level / locator | Question / concepts | Sample / corpus / period | Design / measures | Finding | Limitations | Review module |
|---|---|---|---|---|---|---|---|---|

Read level is record, abstract, full text or user notes. A metadata match does not establish support for a claim. Distinguish “尚未读取” (not read), “未查到” (searched but not found), and “未报告” (absent from the material actually read); specify that read level rather than implying the whole paper omits it. Never infer details from the title. Apply the selected discipline's appraisal fields. Repeated reports of one study are not independent evidence.

## Draft The Review

1. Build an outline with each section's purpose and supporting source IDs. Use the five core skills as needed, not five compulsory output chapters.
2. For each theme, develop a bounded claim, compare supporting and conflicting evidence, explain plausible differences, and state the remaining limit. Attach source IDs and locators to factual claims; label interpretation separately.
3. Include scope/search description, thematic synthesis, method/evidence limitations, and a contribution or gap proportional to coverage. Historical/interpretive work can organize by concepts, debates or periods when analytically justified.
4. Draft only evidence-supported sections. With no sources, deliver an outline/search plan; with abstracts only, mark the synthesis preliminary and avoid full-text methodological claims. Unsupported bridges stay `[需补来源]` rather than becoming asserted findings.
5. Deliver the draft under `## 段落草稿（需作者改写并核对来源）`, with the required warning, followed by the two fixed closing sections. The outline, search log and evidence table can precede the draft. Full review output uses this contract; single-stage output keeps its existing section order.
6. Audit every citation for identity and claim support, check inconsistent constructs and duplicated studies, retain counterevidence, and flag unsupported novelty claims. List missing evidence and concrete next actions. Do not promise submission readiness.
