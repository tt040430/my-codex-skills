# legal-paper-review

中国法学顶级期刊论文审稿评价 Skill（Claude Skill）。

模拟《法学研究》《中国法学》《中外法学》等期刊的匿名同行评审，评估论文的创新性、理论贡献、教义学论证链条质量与退稿风险，输出结构化审稿意见。

## 功能

- **范式识别**：先判断论文研究范式（民法教义学／社科法学／行业问题导向等），避免用错误范式评价；
- **编辑初审模拟**：站在期刊编辑视角做第一轮筛选；
- **核心命题压力测试**：对中心命题做最强反驳（steelman attack）；
- **多角色审稿**：保守教义学／理论创新／制度实践／比较法四类审稿人视角；
- **多维攻击审查**：从十个维度系统攻击论证链条；
- **顶刊价值判断**：对照顶刊审美标准评估发表价值；
- **拒稿风险识别**：逐项排查六类典型退稿模式（R1–R6）；
- **结构化输出**：按固定十段模板输出审稿意见，可复盘、可对照。

### 扩展模块

`socio-legal-integration-module.md`：当论文将法社会学、法经济学等社会科学融入法教义学时启用，审查融入是否经过教义学筛选过滤、是否明示限度、是否承接论证负担。

## 安装

将本仓库的全部 `.md` 文件复制到 Claude 的 skill 目录即可：

```bash
git clone https://github.com/Clara-Ren/legal-paper-review.git
cp legal-paper-review/*.md ~/.claude/skills/legal-paper-review/
```

或在 Claude Code 中将本目录作为一个 skill 直接加载。

## 使用

在 Claude Code 中，将论文全文（或章节）提供给模型，并说明希望进行审稿，例如：

```
请用 legal-paper-review 审稿以下论文：[粘贴论文全文或上传文件]
```

可选参数：

- 指定目标期刊层次，以校准评价标准；
- 说明论文是否涉及"社会科学融入教义学"，以决定是否启用扩展模块；
- 指定重点关注某一类审稿人视角（如只跑保守教义学审稿人）。

## 学术诚信声明

本 Skill 的定位是**评审工具**，模拟同行评议中审稿人的角色：

- 输出的是对论文的**批评性诊断**，不是修改后的文本；
- 不代写、不改写论文任何部分；
- 是否采纳意见、如何修改，完全由作者决定并执行。

请在使用时遵守你所在机构的学术规范与 AI 使用政策。不同期刊与学校对 AI 辅助工具的接受程度不同，投稿前请确认目标期刊的相关规定。
