# Discipline Profile Template

Copy this file under a new stable ID and replace the prompts below with field-specific guidance. This template is not an active profile.

## Scope and Disambiguation
Define included fields, ambiguous terms, adjacent fields and exclusions.

## Question and Concepts
List useful question types, units of analysis and constructs that must not be conflated. Explain when historical, interpretive or conceptual questions fit.

## Search Plan
Give bilingual term families, candidate databases with official links, and an illustrative Boolean query. State that syntax, access and coverage require checking. Separate scholarly literature from primary material.

## Extraction and Appraisal
List fields beyond the common evidence table, appropriate method checks, and limits of inference.

## Synthesis and Gap
Suggest optional organizational axes and one question that could challenge a claimed gap. Do not claim the field actually has that gap.

## Interview Prompts
Provide questions about scope, concepts, evidence and alternative explanations. Ask them conditionally, not all at once.

## Example
Provide a source-free planning example or a properly sourced example. Mark hypothetical content explicitly.
