# 行为检查

`scenarios.json` 是待执行的行为用例，不是通过率报告。结构检查不能证明模型会按指令完成文献综述。

在干净会话中安装总入口或用例指定的单个 Skill，逐条输入 prompt。保存模型、版本、日期、可用工具、完整回答和参考文件读取记录；每条 expected 分别标为通过、失败或无法判断，并给出回答中的证据。不要把同一会话中已纠正过的回答当作首次成功。

重点检查：单题追问是否真的等待回答、无文献时是否停止编写研究结论、单独安装时能否读取嵌套学科文件、用户要求不追问时是否遵守。若要比较质量，应使用同一批真实文献、同一模型和工具，对比普通提示词、v0.2 与 v0.3，并由学科研究者盲评。未完成这些步骤，不报告“质量提升”或真实稿件适用性。

本仓库的同步脚本单元测试单独运行：

```bash
python3 -m unittest discover -s tests -v
bash scripts/check_references_sync.sh
```
